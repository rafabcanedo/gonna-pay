# Contact Us

GonnaPay is a personal study project built to explore modern web technologies and financial management concepts. It is not a commercial product and is intended for learning and portfolio purposes only.

## About this project

GonnaPay was designed as a full-stack study project, combining a Next.js frontend with a Go backend. The goal was to build a real-world application with features like cost splitting, group management, and financial tracking — while following best practices in architecture, UI, and user experience.
